# NETRIX — ربات فروش اشتراک VPN

## چی داری؟
یه اسکلت کامل و ماژولار برای ربات فروش VPN روی تلگرام:
- کیف‌پول + شارژ کارت‌به‌کارت با شناسه‌ی سه‌رقمی رندوم (کول‌داون ۲ هفته‌ای) + پاداش هزار تومانی
- تایید/رد رسید توی یه گروه ادمین با دو تا دکمه
- خرید اشتراک با ۴ دسته (حجمی / نامحدود / مولتی‌لوکیشن / مولتی‌لوکیشن نامحدود) و انتخاب مدت‌زمان
- دو پنل PasarGuard جدا (یکی برای حجمی/نامحدود، یکی برای مولتی‌لوکیشن)
- پنل مدیریت قیمت داخل خود ربات (بدون دست‌زدن به کد)
- گیت عضویت اجباری کانال
- ساختار کاملا ماژولار — هر بخش/دکمه فایل خودش رو داره

## ⚠️ قبل از هر چیز — پنل PasarGuard رو چک کن
آداپتور پنل (`services/panels/pasarguard_panel.py`) بر اساس ساختار استاندارد
API مبتنی بر Marzban نوشته شده (چون PasarGuard فورک Marzbanه). ولی چون
فورک‌ها فرق می‌کنن، **حتما قبل از تست واقعی** برو به:

    https://panel.picofun.ir:8080/docs

و این موارد رو با پنل خودت تطبیق بده:
1. اسم فیلدهای `create_user` (خصوصا `proxies` و `inbounds`)
2. مسیر دقیق endpoint های توکن‌گیری و CRUD کاربر
3. لیست inbound های واقعی پنلت (از `/api/inbounds` بگیر و توی کد جایگزین کن)

## نصب و تست لوکال (VS Code)
```bash
python -m venv venv
source venv/bin/activate   # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# .env رو با مقادیر واقعی پر کن (پایین توضیح داده شده)
python main.py
```
با `RUN_MODE=polling` توی `.env`، ربات مستقیم توی VS Code بالا میاد و آماده‌ی تسته.

## دیتابیس (Supabase — رایگان و دائمی)
1. توی [supabase.com](https://supabase.com) یه پروژه‌ی رایگان بساز.
2. از بخش Settings → Database، connection string رو بردار (فرمت URI).
3. `postgresql://` رو به `postgresql+asyncpg://` تغییر بده و توی `DATABASE_URL` بذار.

## دیپلوی روی Render
1. ریپو رو به گیت‌هاب پوش کن (فایل `.env` هیچ‌وقت نباید پوش بشه — توی `.gitignore` هست).
2. توی رندر یه **Web Service** جدید از روی همون ریپو بساز.
3. Build command: `pip install -r requirements.txt`
   Start command: `python main.py`
4. توی بخش Environment رندر، همه‌ی متغیرهای `.env` رو ست کن، با این تفاوت‌ها:
   - `RUN_MODE=webhook`
   - `WEBHOOK_BASE_URL` = آدرسی که رندر بهت میده (مثلا `https://netrix.onrender.com`)
5. بعد از دیپلوی، یه سرویس رایگان مثل [UptimeRobot](https://uptimerobot.com) یا
   [cron-job.org](https://cron-job.org) بساز که هر ۱۰-۱۴ دقیقه به آدرس
   `https://netrix.onrender.com/health` پینگ بزنه — این‌جوری روی پلن رایگان
   رندر هم نمی‌خوابه.

## گروه تایید رسید
1. یه گروه بساز، ربات رو بهش اضافه کن و ادمینش کن.
2. آیدی عددی گروه رو بگیر (مثلا با فوروارد یه پیام از گروه به `@userinfobot`
   یا از طریق `@RawDataBot`) و توی `DEPOSIT_REVIEW_GROUP_ID` بذار.

## کانال اجباری
`REQUIRED_CHANNEL_ID` رو یوزرنیم کانالت (`@channelusername`) یا آیدی عددیش
بذار. ربات باید ادمین کانال باشه تا بتونه عضویت رو چک کنه.

## نکات امنیتی مهم
- توکن ربات و رمز پنل‌ها فقط توی `.env` — هیچ‌وقت توی کد یا گیت‌هاب پابلیک.
- `.env` توی `.gitignore` هست، مطمئن شو اشتباهی کامیت نشه.
- روی رندر، توکن‌ها رو از طریق Environment Variables ست کن نه از طریق فایل.
